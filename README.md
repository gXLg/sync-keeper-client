# <img align="top" src="https://static.wikia.nocookie.net/core-keeper/images/b/b8/Recall_Idol.png/revision/latest?cb=20220313041921" height="48"> Sync Keeper | Client

World synchronisation solution for Core Keeper

This repository contains open-source code of the Sync Keeper client.
It is a helper utility to play on a remote world with multiple friends.
Sync Keeper supports Windows and Linux.

# Usage

Follow instructions on the [installer page](https://github.com/gXLg/sync-keeper-installer) on how to install Sync Keeper and hook it into Steam.

You can repeatedly run the installer to modify parameters or update the client.

> [!IMPORTANT]
> Do not close the terminal window while running the game!
